# Hospital-Patient-Waiting-List-Analysis
An interactive Power BI dashboard analyzing hospital inpatient and outpatient waiting lists, patient waiting trends, age profiles, case types, and specialty-wise waiting list distribution.
 Hospital Patient Waiting List Analysis Dashboard

 Project Overview

This project focuses on analyzing hospital patient waiting lists using **Power BI**. The analysis includes both Inpatient and Outpatient data to understand patient waiting patterns, waiting list distribution, and monthly trends.

An interactive dashboard was developed to help users monitor waiting lists, compare performance, and identify specialties with higher patient waiting volumes.

Project Objectives

- Analyze hospital inpatient and outpatient waiting list data.
- Compare the latest month's waiting list with the previous year's corresponding month.
- Understand patient waiting list distribution by case type.
- Analyze waiting lists across different age profiles.
- Identify specialties with the highest patient waiting lists.
- Track monthly waiting list trends.

 Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization

📊 Dashboard Features

1. Summary and KPI Analysis
- Latest Month Waiting List
- Previous Year Latest Month Waiting List
- Average and Median Waiting List indicators

2. Waiting List Distribution by Case Type
- Day Case
- Outpatient
- Inpatient

3. Age Profile Analysis
- 0–15 years
- 16–64 years
- 65+ years

4. Specialty-wise Analysis
- Identifies the top 5 specialties with the highest waiting lists.
- Helps understand specialty-wise patient distribution.

5. Monthly Trend Analysis
- Compares Inpatient and Outpatient waiting list trends.
- Tracks monthly changes in patient waiting volumes.

6. Interactive Filters
- Archive Date
- Case Type
- Specialty Name

📈 Key Insights

The dashboard provides insights into:
- Changes in patient waiting lists over time.
- Differences between Inpatient and Outpatient waiting patterns.
- Age-group-wise waiting list distribution.
- Specialties with higher waiting list volumes.
- Monthly trends that support hospital performance monitoring.
